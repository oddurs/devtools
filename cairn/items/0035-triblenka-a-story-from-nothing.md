## Where it stands

No story, and the only tool on the site in the `design` state: designed in the
open, documented before it is built. Its page already says so, and says the
demo is the design rather than a program running.

Today the page carries a typed session. When that goes (0006) it carries
nothing, so this item is part of what gates it.

## What it should show

Nothing runs yet, so there is nothing to record — and pretending otherwise
would break the site's one rule. What it can honestly show is the design: the
documented API, the architecture, whatever the design docs draw. Decide
whether that is screens of a document, and whether the page says clearly
enough that it is. Possibly this page is finished already and the honest
answer is that it waits for code.
